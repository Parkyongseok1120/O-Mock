O-MOCK Windows Shipping 배포 안내
=================================

1. 실행
-------
- Windows\O_Mock.exe를 실행합니다.
- Windows Defender 방화벽 창이 나타나면 같은 사설 네트워크에서 플레이할 수 있도록 허용합니다.
- 모든 참가자는 같은 버전의 배포본을 사용해야 합니다.

2. LAN 멀티플레이
-----------------
- 현재 배포본은 같은 공유기/사설망에 연결된 PC 사이의 LAN 플레이를 대상으로 합니다.
- 호스트: 메인 메뉴에서 방 설정을 정한 뒤 HOST ROOM을 누릅니다.
- 참가자: 방 목록을 새로고침하고 원하는 방을 선택한 뒤 JOIN SELECTED를 누릅니다.
- 잠금방은 방 목록에서 선택하고 비밀번호를 입력해야 합니다. 잠금방의 직접 IP 접속은 지원하지 않습니다.
- 인원은 방 설정에 따라 2~4명이며, 모든 참가자가 READY 상태가 되면 호스트가 시작할 수 있습니다.
- 진행 중인 방 재입장과 호스트 이전은 현재 지원하지 않습니다.
- 인터넷 공개 매치메이킹이나 계정 인증이 아니라 신뢰할 수 있는 LAN용 접근 제어입니다.

3. 주요 조작
------------
- 우클릭 드래그: 3D 카메라 회전
- 마우스 휠: 확대/축소
- 좌클릭: 보드 칸 선택/돌 놓기/예측 대상 확인
- 숫자 1~5 또는 인벤토리 슬롯 클릭: 아이템 선택 및 사용
- ESC: 메뉴 또는 현재 UI 닫기

4. 커스텀 방과 게임 기능
-------------------------
- 보드 크기, 최대 인원, 개인 시간, 턴 시간, 아이템, 미니게임, 비밀번호를 설정할 수 있습니다.
- 봇 수를 0~3명으로 설정할 수 있습니다. 모든 사람이 준비하면 빈 좌석에 봇이 들어오며, 사람 참가자가 많으면 봇 수가 자동으로 줄어듭니다.
- 봇은 서버에서 승리/방어 수를 판단하고, 보유 아이템을 일정 확률로 합법적인 대상에 사용한 뒤 돌을 놓습니다.
- 인벤토리가 가득 찬 상태에서 새 아이템을 받으면 교체할 기존 아이템을 직접 선택해야 합니다.
- 고급 예측 UI는 승리 가능 칸, 상대 승리 위협, 견인 출발/도착, 강탈 가능 돌을 색으로 구분합니다.
- 정확한 오목, 아이템, 미니게임 규칙은 동봉된 문서 폴더의 PDF를 확인하십시오.

5. 밸런스 통계
--------------
- 호스트는 경기 종료 시 통계를 다음 위치에 누적합니다.
  Saved\Balance\O_Mock_Matches.csv
  Saved\Balance\O_Mock_BalanceSummary.json
- 경기 시간, 보드/인원/좌석별 결과, 아이템 사용량, 미니게임 횟수, 시간 초과와 이탈 등이 기록됩니다.
